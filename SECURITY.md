# Security policy

## Supported versions

Security fixes are made against the latest tagged release and the `main` branch.
Pre-release builds may change without compatibility guarantees.

## Reporting a vulnerability

Please use GitHub's private **Report a vulnerability** flow in this repository's
Security tab. If private vulnerability reporting is temporarily unavailable,
contact [@sebkouba](https://github.com/sebkouba) without including sensitive
details in a public issue.

Please include the affected version, macOS version, impact, reproduction steps,
and any suggested mitigation. Expect an acknowledgement within seven days.

Do not publish conversation data, credentials, source-history files, database
files, or generated transcripts in an issue or proof of concept.
