# Changelog

All notable changes to Histories will be documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and
the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Local-first macOS conversation browser and CLI for Codex, Pi, and ChatGPT.
- SQLite FTS5 search, clean/full Markdown exports, selection, preview, and Finder
  actions.
- Private derived-data permissions, orphan cleanup, and on-demand full exports.
- Cross-process refresh locking and strict ChatGPT import validation.
- Rust parser fixtures and frontend regression tests.
